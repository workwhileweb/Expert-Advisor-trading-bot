Hoàn toàn có thể áp dụng các thuật toán trên vào MQL5 (MT5). Hiện nay, MT5 đã hỗ trợ rất mạnh mẽ cho việc tích hợp AI và kết nối bên ngoài.
## 1. Áp dụng vào code MQL5
Bạn có thể hiện thực hóa các thuật toán nhận diện mô hình nến ngay trong MQL5 bằng cách sử dụng các hàm xử lý mảng giá (Open, High, Low, Close). [1, 2] 

* Thư viện có sẵn: MQL5 có các thư viện toán học như ALGLIB (hỗ trợ phân tích thống kê, giải quyết các bài toán hồi quy và phân loại) tích hợp sẵn trong IDE MetaEditor.
* Ma trận và Vector: MT5 hiện đã bổ trợ kiểu dữ liệu matrix và vector giúp việc tính toán các phép toán đại số tuyến tính (cốt lõi của machine learning) nhanh hơn nhiều so với trước đây. [3, 4, 5] 

## 2. Gọi API từ bên ngoài
MQL5 hỗ trợ gọi API rất tốt thông qua hàm WebRequest(). [6, 7] 

* Gửi dữ liệu: Bạn có thể gửi dữ liệu nến hiện tại lên một Server (viết bằng Python, Node.js, v.v.) qua giao thức HTTP GET/POST.
* Nhận kết quả: Server xử lý bằng các mô hình phức tạp rồi trả về tín hiệu "Mua/Bán" hoặc "Tăng/Giảm" dưới dạng JSON để MQL5 thực thi lệnh.
* Lưu ý: Để dùng WebRequest(), bạn phải thêm URL của API vào danh sách "Allow WebRequest" trong phần Tools > Options > Expert Advisors của MT5. [7, 8, 9] 

## 3. Code Deep Learning trực tiếp trên MQL5
Bạn có thể code Deep Learning trực tiếp, nhưng thường sẽ khó và tốn công hơn so với Python. Tuy nhiên, có các hướng đi sau:

* Viết từ đầu (Scratch): Bạn có thể tự code các lớp nơ-ron (Layers), hàm kích hoạt (Activation functions) và lan truyền ngược (Backpropagation) bằng hướng đối tượng (OOP) trong MQL5.
* Sử dụng ONNX (Khuyên dùng): Đây là cách chuyên nghiệp nhất hiện nay. Bạn train mô hình Deep Learning (như LSTM, CNN) bên ngoài bằng Python (TensorFlow/PyTorch), sau đó xuất ra định dạng .onnx. MQL5 có thể nạp trực tiếp file này để chạy dự báo (Inference) cực kỳ nhanh mà không cần cài thêm Python trên máy chạy bot.
* Thư viện bên thứ ba: Có các thư viện mã nguồn mở như ASQ NeuralNet cho phép xây dựng mạng nơ-ron sâu (DNN) thuần MQL5 mà không cần DLL bên ngoài. [5, 10, 11, 12]
