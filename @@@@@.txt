# 1. Moving Average Trend Following

Đây là nhóm cổ điển nhất, dùng cực nhiều trong thực chiến.

## Ý tưởng

Nếu giá nằm trên trung bình động → xu hướng tăng.
Nếu MA ngắn hạn cắt lên MA dài hạn → bullish.
Ngược lại → bearish.

## Ví dụ

* EMA20 > EMA50 → tăng
* EMA20 cắt xuống EMA50 → giảm

## Pseudocode

```python
ema_fast = EMA(close, 20)
ema_slow = EMA(close, 50)

if ema_fast > ema_slow:
    trend = "UP"
else:
    trend = "DOWN"
```

## Biến thể thực tế

* Golden Cross / Death Cross
* Triple EMA filter
* Hull MA
* VWMA (volume weighted)

## Ưu điểm

* Rất đơn giản
* Hoạt động tốt trong trend mạnh

## Nhược điểm

* Sideway là chết
* Lag

# 2. Candlestick Pattern Recognition

Thuật toán nhận dạng mô hình nến.

## Ví dụ pattern

* Hammer
* Engulfing
* Morning Star
* Shooting Star
* Doji

## Ý tưởng

Mỗi pattern là một tín hiệu xác suất.

Ví dụ:

* Bullish Engulfing → khả năng đảo chiều tăng
* Shooting Star → khả năng giảm

## Pseudocode

```python
if candle[-1].body > candle[-2].body and \
   candle[-1].close > candle[-2].open:
    signal = "BULLISH_ENGULFING"
```

## Thực tế

Nhiều bot dùng thư viện:

* TA-Lib
* pandas-ta

## Vấn đề lớn

Pattern đơn lẻ thường edge rất yếu.

Người chuyên nghiệp thường:

* lọc theo volume
* lọc theo trend lớn
* lọc theo volatility

# 3. Support / Resistance Breakout

Đây là thứ cực phổ biến trong crypto.

## Ý tưởng

Nếu giá phá kháng cự mạnh với volume cao → xác suất tăng tiếp.
Nếu thủng hỗ trợ → xác suất giảm tiếp.

## Logic

```python
resistance = highest(high, 20)

if close > resistance and volume > avg_volume:
    signal = "BREAKOUT_UP"
```

## Thực tế

Market maker và trader lớn rất thích chiến lược này.

## Các biến thể

* Donchian Channel
* Turtle Trading
* Range Breakout

---

# 4. RSI Mean Reversion

Dùng oscillator để dự đoán hồi giá.

## Ý tưởng

RSI quá thấp → quá bán → dễ bật lên
RSI quá cao → quá mua → dễ giảm

## Ví dụ

```python
rsi = RSI(close, 14)

if rsi < 30:
    signal = "BUY"

if rsi > 70:
    signal = "SELL"
```

## Quan trọng

RSI không phải predictor tương lai tuyệt đối.

Nó chỉ nói:

> “giá đang lệch quá xa khỏi trạng thái cân bằng”.

# 5. MACD Momentum Detection

Xác định động lượng.

## Ý tưởng

* Momentum tăng → khả năng tiếp diễn trend
* Momentum giảm → khả năng đảo chiều

## Dùng thực tế rất nhiều

Đặc biệt trên:

* crypto
* forex
* index

## Logic

```python
macd = EMA12 - EMA26
signal = EMA(macd, 9)

if macd > signal:
    trend = "UP"
```

* trending down
* sideways
* high volatility

HMM cố đoán state hiện tại từ chuỗi nến.

## Input

* volatility
* volume

## Output

```python
state = model.predict(features)
```

# 9. Statistical Momentum

Rất phổ biến ở hedge fund.

## Ý tưởng

Tài sản tăng mạnh gần đây có xu hướng tiếp tục tăng.

## Ví dụ

```python
momentum = close / close_90_days_ago

if momentum > threshold:
    buy()
```

## Đây là anomaly có thật

Momentum effect là một trong những market anomaly nổi tiếng nhất tài chính.

# Điều quan trọng nhất

Không có thuật toán nào:

> “dự đoán chắc chắn tương lai”.

Thực tế tất cả chỉ là:

```text
Estimate probability distribution
```

Ví dụ:

| Tình huống           | Xác suất          |
| -------------------- | ----------------- |
| Breakout volume mạnh | 62% tiếp tục tăng |
| RSI quá bán          | 55% hồi           |
| Golden cross         | 58% bullish       |

Professional trading thực chất là:

```text
positive expectancy
=
(winrate * avg_win)
-
(lossrate * avg_loss)
```

chứ không phải đoán đúng tuyệt đối.
